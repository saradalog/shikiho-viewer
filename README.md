# 四季報ビューア

四季報「年度比較」シート（2026年4集・2580銘柄）をスマホで見て、監視銘柄と理論株価を管理するWebアプリ（PWA）です。GitHub Pages で配信し、ホーム画面に追加して使います。

- このリポジトリには画面のコードだけを置いています。四季報のデータと監視リストは、Googleスプレッドシートに付けた Apps Script から、合言葉を知っている人だけが取得できます。
- 四季報データは端末内（IndexedDB）に保存されるので、オフラインでも閲覧できます。
- 監視リストは「四季報ビューア 監視銘柄」スプレッドシートと同期します。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（一覧・銘柄詳細・監視銘柄・設定） |
| `manifest.webmanifest`, `icons/` | ホーム画面に追加したときの名前とアイコン |
| `sw.js` | 画面部品のキャッシュ（オフライン起動用） |

Apps Script のコード（`Code.gs`）は合言葉を含むため、このリポジトリには置いていません。
