# 四季報ビューア

他のAIで編集するときは、まず `AGENTS.md` を読ませてください。

四季報「年度比較」シート（2026年4集・2580銘柄）をスマホで見て、監視銘柄と理論株価を管理するWebアプリ（PWA）です。GitHub Pages で配信し、ホーム画面に追加して使います。

- このリポジトリには画面のコードだけを置いています。四季報のデータと監視リストは、Googleスプレッドシートに付けた Apps Script から、合言葉を知っている人だけが取得できます。
- 四季報データは端末内（IndexedDB）に保存されるので、オフラインでも閲覧できます。
- 監視リストは「四季報ビューア 監視銘柄」スプレッドシートと同期します。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（一覧・銘柄詳細・監視銘柄・設定） |
| `manifest.webmanifest`, `icons/` | ホーム画面に追加したときの名前とアイコン |
| `sw.js` | 画面部品のキャッシュ（オフライン起動用） |
| `sectors.json` | 銘柄コード→東証17業種（業種内回帰に使う） |

Apps Script のコード（`Code.gs`）は合言葉を含むため、このリポジトリには置いていません。

## 理論株価の計算（2026-11 改定）

[fair-value-backtest] での検証（2017〜2021年起点、5年後リターン）で採用した方法に切り替えた。

- **本体：残余利益モデル** 1株純資産＋（予想ROE−資本コスト）×純資産 を、ROEが10年で資本コストに戻る前提で割引合計。資本コストは時価総額2,500億円以上6%・300億円以上8%・それ未満10%。過去3期と今期予想がすべて黒字でない銘柄は参考値。
- **確認：業種内回帰** 17業種ごとに 対数PBR を 予想ROE・予想EPS伸び率・ROEのぶれ・規模 で当てはめた、付くはずの株価。
- 判定は「両方で割安」「残余利益で割安」などを銘柄詳細に表示。監視リストに送る自動理論株価は残余利益の値。

## 株主還元利回りと「割安×高還元」（2026-11 追加）

検証（fair-value-backtest の combo.py）で、残余利益の割安上位のうち株主還元利回りが中央値以上の銘柄だけを買うと、5年後リターンの中央値が日本+9.8pt・米国+5.4pt改善した。

- 株主還元利回り＝直近期の1株配当÷株価＋自社株買いによる株数の減少率（シート「銘柄一覧」X列、J-Quantsから毎日計算）
- 理論株価（残余利益）を下回り、黒字続きで、還元利回りが黒字続きの銘柄の中央値以上なら「割安×高還元」の印を出す
